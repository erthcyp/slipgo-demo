# SlipGo — concierge test prototype

Smallest viable prototype for the SlipGo venture project (DES:324, SIIT Thammasat).
A shop issues a code, a shopper redeems against a ฿500 threshold, and our team
applies the validation by hand. It connects to no parking system, no LPR camera
and no tenant POS.

Data shown in the app is sample data, not test results.
